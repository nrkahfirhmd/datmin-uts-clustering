# Image Segmentation Clustering

Repository ini merupakan mini project untuk menyelesaikan UTS mata kuliah Data Mining. Mini project ini bertujuan untuk melakukan clustering dari warna-warna dominan pada input gambar. Hasilnya gambar akan ditampilkan kembali hanya dengan warna-warna yang dominan.
